# Student Attendance Tracker

A simple full-stack app to manage subjects and track attendance. Built with React (frontend), Node/Express (backend), and MongoDB.

## Features
- Add, edit, and delete subjects
- Track attended, missed, and total classes
- Attendance percentage and 75% target helper

## Tech Stack
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express, Mongoose
- Database: MongoDB (Atlas or local)

## Project Structure
- frontend/ — React app
- backend/ — Express API
- backend/models — Mongoose schemas
- backend/routes — API routes


## How to Run
1) Install dependencies in backend and frontend
2) Start backend server
3) Start frontend dev server
4) Open the frontend URL shown in terminal

## API Endpoints
- GET /subjects
- POST /subjects
- PUT /subjects/:id
- DELETE /subjects/:id
- GET /ping
